# Interactive Checklist App
An interactive checklist and project management app designed to help users organise tasks, manage multiple projects, and track progress efficiently. Built with React and CSS for the frontend, Node.js for the backend, and Supabase for authentication and data persistence, the app features drag-and-drop task organisation, real-time progress tracking, and user accounts to keep projects organised and accessible.

### Features
- **Checklist & Task Management:** Create checklists, add tasks, and track progress in an intuitive interface.
- **Drag-and-Drop Reordering:** Easily rearrange tasks and checklists to prioritise work and organise projects.
- **Real-Time Progress Tracking:** Visual progress bars update automatically as tasks are completed, making it easy to monitor progress.
- **Multi-Project Organisation:** Create and manage multiple projects, each with its own set of checklists and tasks.
- **User Authentication & Data Persistence:** Sign up and log in securely to access saved projects and checklists across sessions (including Google sign in).
